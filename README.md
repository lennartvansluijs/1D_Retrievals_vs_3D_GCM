# Robustness of 1D Retrievals with 3D HRS
This repository contains the data and notebooks to reproduce the figures of the accompanying paper: <em>"Assessing robustness and bias in 1D retrievals of 3D Global Circulation Models at high spectral resolution: a WASP-76 b simulation case study in emission"</em>. All Jupyter Notebooks can be found in the <em>/notebooks</em> directory. The paper is now available on the arXiv: https://arxiv.org/abs/2507.16687

In case of any questions, please email lsluijs@umich.edu.
